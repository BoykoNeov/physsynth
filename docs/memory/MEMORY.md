## Working rules & preferences

- [Commit & push at batch end](commit-push-at-batch-end.md) — standing rule: batch/session end → update memory+docs, commit, push; "commit" always pushes too (never split)
- [Respect ruff line length](respect-ruff-line-length.md) — ≤100 chars in the FIRST draft; CI runs `ruff check .` as a fail-fast gate; never write long then reflow
- [Destructive undo discipline](destructive-undo-discipline.md) — never undo a temp edit with `git checkout -- <file>`; it restored HEAD and DISCARDED a whole batch's uncommitted core work — revert the edit itself, and commit a checkpoint before deliberately breaking code
- [Identify processes before killing](identify-processes-before-killing.md) — read the command line first; this machine runs the user's own Python, I killed two of theirs assuming they were my pytest orphans
- [Port reclaim modus operandi](port-reclaim-modus-operandi.md) — port busy? identify the PID's command line; reclaim only if it's a stale run of THIS program, else try the next port
- [Unphysical params are a feature](unphysical-params-are-a-feature.md) — prefer effective-coefficient APIs that permit inconsistent combos over materials surfaces that forbid them; offer realism via a helper, never impose it
